# Product

## Problem

Personal financial transactions are distributed across eSewa and
multiple bank accounts.

There is no single place to analyse them.

## MVP

The user can:

1. Upload a CSV statement.
2. Select the financial institution.
3. Preview the detected transactions.
4. See new vs duplicate transactions.
5. Import new transactions.
6. View transaction history.
7. View income and expenses.

## Later Features

- automatic categorisation
- spending categories
- monthly analytics
- recurring payment detection
- budgets
- anomaly detection
- AI financial assistant
- net-worth tracking
